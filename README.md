# Linux System Security Labs

A collection of Linux security projects completed in a Kali Linux environment.

## Security Areas

- Linux user and account security
- Password and authentication security
- File and directory access control
- Access Control Lists (ACLs)
- Sudo and privilege management
- SSH security and system hardening
- Two-factor authentication
- Security auditing and monitoring

## Environment

- Kali Linux
- Linux command line
- Local virtualized environment

## Tools and Technologies

- PAM / libpam-pwquality
- Google Authenticator
- auditd
- auditctl
- ausearch
- sudo
- systemctl
- SSH
- ACL utilities
- chage
- passwd
- Bash scripting

## Skills

- Linux user and account administration
- Password policy configuration
- File and directory permissions
- Access Control Lists (ACLs)
- Privilege management
- SSH key-based authentication
- Root login restriction
- Two-factor authentication
- Authentication log analysis
- Linux security auditing
- Security control testing
- Basic security audit automation
